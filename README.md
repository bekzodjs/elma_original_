# ELMA Premium Vue 2.0

Vue 3 + Vite + Pinia + Vue Router.

## Ishga tushirish
1. Node.js o‘rnating.
2. Shu papkada terminal oching:
   npm install
   npm run dev
3. Brauzer: http://localhost:5173

- Dashboard statistikasi
- Mahsulot CRUD
- Yangilik qo‘shish/o‘chirish
- Murojaatlarni ko‘rish
